# reliability-eval

## 0.1.0

### Minor Changes

- 51605f4: Initial v0.1.0 release.

  Calibration-first LLM evaluation library for Node/TypeScript. Ships accuracy, Expected Calibration Error (ECE), and Brier score alongside Wilcoxon signed-rank and Spearman rank correlation tests. Statistical implementations are validated against scipy.stats reference values to 1e-4 tolerance. Providers use raw fetch with no SDK dependencies.
